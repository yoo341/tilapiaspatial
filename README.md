# TilapiaSpatial
Mobile data-collection and spatial-analysis app: clustering of fish mortality on small tilapia farms, Volta Region (shared water).

## Host on GitHub Pages
1. Create a **public** repository (e.g. `tilapia-app`). Add file > Upload files: upload everything in this folder (including the hidden `.nojekyll` if your browser shows it; it is optional).
2. Settings > Pages > Source: **Deploy from a branch** > Branch **main**, folder **/ (root)** > Save.
3. After 1-2 minutes open `https://YOUR-USERNAME.github.io/tilapia-app/` in **Chrome on Android**.
4. Tap **Install app** (top right) or Chrome menu > Install app.

Updating: after editing files change `tilapia-v2` in `sw.js` (e.g. `tilapia-v3`) so phones refresh.
Data are stored only on each phone (localStorage). Export CSV regularly. Keep exported farm coordinates private.
